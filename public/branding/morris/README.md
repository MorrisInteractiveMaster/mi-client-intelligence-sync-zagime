The sidebar uses the transparent mark published by Morris Interactive, with the company name rendered as text beside it. The PNG is a byte-for-byte copy of the [official site icon](https://morrisinteractive.ca/wp-content/uploads/2026/07/cropped-MI-Favicon-180x180.png).
